## What is Nexus AI?

Nexus AI is a multi-agent retrieval-augmented generation (RAG) system. A router agent picks a
route (question answering, summarizing, comparing, table extraction, code or image tasks), a planner
breaks multi-part questions into steps, and a retrieval agent runs hybrid search that combines dense
vector search with BM25 keyword search and a re-ranker. A verifier agent checks each answer against
the retrieved sources.
